# UI/UX Wireframe — todo-list-desktop

> 模式: **design new UI** + **AI UX review**(双模式,因 AIPanel 涉及 agent 表面)
> 适用:作为 `tasks.md` 6.x 视图任务与 8.x AI 任务的执行依据
> 平台:Electron 桌面(Windows / macOS / Linux),`contextIsolation`+`sandbox`
> 目标用户:个人知识工作者 / 开发者 / 研究者(重度 Markdown + 重度 AI)

---

## 1. 设计方向(Design Thesis)

### 视觉主张(Visual Thesis)
**"静默的画布,信息优先"** —— 借鉴 Linear / Things 3 / Obsidian 的克制语汇:
- 暗色为主,中性灰层级(`slate-900 → slate-700 → slate-300`)承载信息密度
- 单一品牌色 `indigo-500/400` 用于"AI 在场"语义(草稿、提示、确认)
- 不依赖插画与渐变;状态由排版层级与图标语义传达
- 字体:UI 用系统 sans(`-apple-system, Segoe UI`),代码 / 时间戳 / TODO ID 用 `JetBrains Mono`

### 交互主张(Interaction Thesis)
- **键盘优先**:每个主操作 1 步;全局调色板(`Ctrl/⌘+K`)覆盖 80% 的二级操作
- **AI 是同位素而非主角**:AIPanel 默认折叠,按需展开,绝不强占视线
- **撤销是一等公民**:`Ctrl/⌘+Z` 跨视图生效,危险操作提供 8 秒 toast 撤销
- **可逆性分级**:DSH 的 destructive tool(删 TODO / 覆盖历史)走 `Block` 门(modal),`notify + undo` 用于非破坏性(tool 自动写回)

## 2. Inbox 快速捕获窗口(Capture Window)

### 触发与生命周期
- 全局快捷键 `Ctrl/⌘+Shift+T`(可在 settings 改)从**任意应用**唤起
- 独立 `BrowserWindow`,无边框、`alwaysOnTop: true`、`width: 520, height: auto`
- 失焦 5 秒 / `Esc` / 提交后自动隐藏;**不抢焦点**(可设 macOS `panel` 行为)

### 布局(ASCII)

```
┌──────────────────────────────────────────────────────────┐
│  ▣ Quick capture                                  Esc ✕  │  ← header 32px
├──────────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────────────┐  │
│  │ 明天上午 10 点和 Bob 评审登录页 A/B 测试稿          │  │  ← input 48px
│  │ !p1 @design #评审                                    │  │     auto-grow
│  └────────────────────────────────────────────────────┘  │
│                                                            │
│  AI 解析预览  (按 Enter 显示,可按 Tab 跳过)               │
│  ┌────────────────────────────────────────────────────┐  │
│  │ ▣ 标题    完成登录页 A/B 测试评审                    │  │
│  │ ▣ 截止    明天 10:00                                 │  │
│  │ ▣ 优先级  P1                                         │  │
│  │ ▣ 项目    design                                     │  │
│  │ ▣ 标签    评审                                       │  │
│  │                                  [编辑] [捕获 ↵]   │  │
│  └────────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────────┤
│  ⌘+Enter 直接捕获 · Tab 跳过 AI · Esc 关闭                │  ← footer 微提示
└──────────────────────────────────────────────────────────┘
```

### 主操作
- **`Enter`** → 提交解析结果(若 AI 解析可见)或原文(若 AI 不可用)
- **`⌘+Enter`** → 跳过 AI,直接以原文提交(节省时间 / 离线)
- **`Tab`** → 在 AI 解析的字段间跳转;按 `Shift+Tab` 反向
- **`Esc`** → 关闭窗口,丢弃草稿(下次唤起会恢复最近 1 条草稿 60 秒)

### 状态覆盖

| 状态 | 表现 |
|---|---|
| **happy** | 输入即解析,200ms 内显示 preview(本地快速通道)或 1-2s 显示(DeepSeek) |
| **empty** | input 焦点提示:`按 ⌘+Enter 直接捕获,或输入自然语言让 AI 解析` |
| **loading AI** | preview 区显示骨架屏 + "AI 正在解析…" (动画非旋转 spinner,是字段逐个点亮) |
| **AI error** | preview 区不显示,改在 footer 红色:`DeepSeek 不可达,按 ⌘+Enter 直接提交` |
| **no key** | 首次:input 下方一条 hint `去 Settings 添加 DeepSeek API key 以启用 AI 解析` + 设置链接;不阻塞提交 |
| **offline** | footer 显示 `离线模式 · AI 已禁用`;仍可 `⌘+Enter` 提交 |

### 微复制(用户口吻)
- 错误:不是"AI service unavailable",而是 `DeepSeek 现在连不上,稍后重试或按 ⌘+Enter 直接捕获`
- 成功 toast(主窗口):`已捕获 → 设计 / 评审` (而非 `Item added`)

### 可访问性
- `role="combobox"`,`aria-expanded`,`aria-controls` 指向 preview 区域
- 解析预览用 `aria-live="polite"`,只在 preview 真正变化时 announce
- 焦点陷阱:窗口内循环;Esc 关闭
- 目标尺寸:input 全宽 ≥ 44px;按钮 36×36 满足 desktop AA(移动端才需 44)

### 主操作
- **保存**:`⌘+S` 写入 DB + 文件,200ms 内底部状态栏 `已保存 14:32:08`
- **AI 草稿**:`⌘+Shift+G` 触发 `draftProgressSkill`,内容插入光标,标黄 + AI 标记
- **AI 总结**:`⌘+Shift+S` 触发 `summarizeSkill`,summary 浮窗显示
- **新建绘图**:绘图 tab `+` 唤起 Excalidraw panel(右侧 480px 抽屉)
- **历史**:点 ⏱ 弹出 vList 抽屉,选中预览 diff,⌘+Enter 回滚
- **删除**:`⌘+D` 弹 modal:侧栏 destructive 门(见 §5)

### 状态覆盖

| 状态 | 表现 |
|---|---|
| **happy** | 同步滚动:`source ↔ preview` 双向;右侧有未保存标记 `●` |
| **loading** | 编辑器骨架屏 + 右上角 `载入中…`,≤ 200ms |
| **empty body** | 预览区:`还没记录进展 · 按 ⌘+Shift+G 让 AI 起草,或直接开始输入`(动词 CTA + AI 引导) |
| **AI 草稿失败** | 草稿面板红色 hint:`DeepSeek 不可达 · 起草暂停`;编辑器仍可用 |
| **版本冲突** | 浮窗:`此 TODO 在另一窗口被修改 · 查看差异 / 强制覆盖 / 放弃` |
| **没有绘图** | 绘图 tab:`还没有画板 · [+ 新建第一个]`,给引导 |
| **离线编辑** | 状态栏:`离线 · 本地保存中`;联网后自动 reconcile |

### 可访问性
- 编辑区 `role="textbox"`,`aria-multiline="true"`,`aria-label="TODO Markdown 源"`
- 预览区 `aria-live="polite"`,只在内容真正变化时 announce
- 同步滚动:`prefers-reduced-motion: reduce` 时跳过动画同步,直接跳到位置
- `Tab` 在编辑器内部循环;`F6` 跨 panel 跳转
- 绘图缩略图加 `aria-label="绘图:<title>,修改于 <相对时间>"`

## 5. AIPanel 与 AI UX(Agent Surface)

AIPanel 是 agent 表面,适用 **Craft Bar 的 4 行 agent 维度**。

### 布局(ASCII,展开态)

```
┌─────────────────────────────────────────────────────────┐
│ AI 助手 · deepseek-reasoner                  [▾▴]  ⌘.  │
├─────────────────────────────────────────────────────────┤
│ 会话历史(可编辑/可删除/可导出)                            │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 你 14:30                                          │  │
│  │ 帮我把本周完成的 TODO 整理成周报                   │  │
│  ├──────────────────────────────────────────────────┤  │
│  │ AI 14:31 · deepseek-reasoner · 23s · ¥0.04       │  │
│  │ 已调用 3 个工具:                                   │  │
│  │   ✓ todo_search({createdAfter: 7d}) → 8 项         │  │
│  │   ✓ todo_stats() → 完成率 62%                     │  │
│  │   ✓ content_write_body({id: "周报-2026-W36"})    │  │
│  │                                                    │  │
│  │ 周报已写入 TODO "周报-2026-W36"。                  │  │
│  │ [打开 ↗]   [重做]   [↶ 撤回]                       │  │
│  └──────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│ [输入框 · 多行 · 始终可用 · 不在生成中禁用]              │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 给"完成登录页 A/B 评审"起草进展…                    │ │
│ └────────────────────────────────────────────────────┘ │
│ ⌘+Enter 发送 · Tab 让 AI 改主意 · Esc 取消              │
└─────────────────────────────────────────────────────────┘
```

### Agent UX 4 维度(spec-mapped to design.md / ai-assistant spec.md)

| 维度 | 落实 |
|---|---|
| **Steerability 可驾驶** | 用户输入框**始终可用**(`disabled` 只在发送瞬间 200ms 内);生成中可追加:"再加上完成率"→ append 到当前目标;`Tab` 触发"让 AI 改主意"(重写上一次输出) |
| **Action reversibility 动作可逆** | 三级门:① `auto`(纯读取 / 草稿写入)无需确认;② `notify + undo`(非破坏性写入)→ 8s toast `已写回周报 · [撤销]`;③ `block`(删 TODO / 覆盖历史 / 删绘图)→ modal:`"让 AI 删除这个 TODO?"` + 永久撤销路径 |
| **Cost visibility 成本可见** | 每条 AI 回复顶部一行 `· deepseek-reasoner · 23s · ¥0.04`;`/settings` 提供本月累计;**用户单位**(¥/$)而非 token 数 |
| **Memory legibility 记忆可读** | "会话历史"区列出本会话所有调用,每条可点击看详情(输入 / 输出 / 工具调用);`Forget this` 按钮单独遗忘某次,**不提供全局 wipe**(避免误删);`Settings → AI Memory` 看跨会话记忆 |

### Permission Modal(destructive tool 拦截)

```
│                                                  │

│  ┌──────────────┐  ┌─────────────────────────┐  │
│  │ 拒绝          │  │ 允许这次删除            │  │
│  └──────────────┘  └─────────────────────────┘  │
│                                                  │
│  ☐ 30 秒内不再询问同类操作                          │
└──────────────────────────────────────────────────┘
```
- **等权重按钮**(DSA Article 25):拒绝 / 允许 同尺寸同色阶,仅主操作略重
- **30 秒内不再询问** = `dsh-permission` 一次性 grant 同一类 tool
- 超时未响应 = 自动拒绝(避免 AI 长时挂起)

### 状态覆盖

| 状态 | 表现 |
|---|---|
| **happy streaming** | 文字逐 token 出现;`prefers-reduced-motion` 时改为每 100ms 一次批量插入 |
| **生成中** | 输入框底部:`生成中… [Stop ⌘.] [改主意 Tab]`;stop 后保留已生成部分 |
| **error** | 行内红色 hint:`DeepSeek 不可达 · 检查网络 / API key`,输入框仍可用 |
| **permission asked** | modal 居中,背景 dim 50%,焦点锁在 modal 内 |
| **rate limit** | `DeepSeek 限流 · 22s 后重试`(倒计时 + 自动重试),输入框可用 |
| **no key** | 顶部红条:`未配置 API key · 去设置`;面板仍展示历史,但新请求被阻断 |

### 可访问性
- 流式区域 `aria-live="polite"`,节流到每 200ms 一次 announce(避免读屏刷屏)
- 工具调用列表 `<ul>` + `<button>` 可逐条展开看详情
- Permission modal `role="alertdialog"`,焦点陷门,Esc = 拒绝

## 9. 跨界面一致性

### 通用交互
| 模式 | 行为 |
|---|---|
| 删除 | ⌘+D → modal "移到回收站 · 30 天可恢复"(destructive gate) |
| 撤销 | ⌘+Z 跨视图;危险操作后 8s toast `已删除 · [撤销]` |
| 全局搜索 | ⌘+K 唤起命令面板 |
| 切换主题 | ⌘+Shift+T(在 capture 之外的全局),settings 也可改 |
| 关闭主窗口 | 不退出,最小化到托盘;托盘菜单"退出"才真正退出 |
| AI 草稿接受 | `⌘+Shift+Y`(AI 草稿写入后,焦点回到编辑器) |
| AI 草稿拒绝 | `Esc` |

### 通知(toast)规范
- 位置:右下角,堆叠 ≤ 3
- 自动消失:成功 4s,错误 8s 或手动关闭
- 用户口吻:`已捕获` 而非 `Item created`

### 错误恢复(全应用)
- 错误分两类:**瞬时**(网络抖动)→ 自动重试 1 次 + toast;**持续**(权限/数据损坏)→ modal "出了什么问题 · 建议下一步"
- **永远不静默吞错**(spec: `Provider failure handling`)
