# 精简悬浮模式

悬浮窗独立显示，开启后立即常驻，主窗口最小化或恢复不改变它的显示状态，不再提供标题栏精简模式按钮。
主窗口保留在任务栏，恢复主窗口或点击任务打开详情时，小窗继续常驻。
个人头像菜单、托盘右键菜单和 Windows 任务栏右键任务菜单提供「显示悬浮窗／隐藏悬浮窗」，标签跟随当前状态。通用设置不再提供悬浮窗配置。
显示状态持久保存：上次开启则下次启动自动显示，上次隐藏则继续隐藏。显示小窗不会抢走其他应用的焦点。
小窗默认内容宽 240px、高 172px，每行 26px。按当前可用高度显示完整任务行，不显示滚动条，不限制固定任务数量；标题显示当前可见数和总数。
可拖动窗口边缘或角落调整宽高（最小 200 × 92px）。拖高窗口显示更多任务，任务减少时不自动缩短。
悬浮窗自身菜单的「恢复紧凑尺寸」恢复默认内容高度 172px。
今日待办优先，同组按截止时间从近到远排列，无截止时间排在后面；
相同截止时间按最近更新排序。已完成、已取消、已归档和已删除任务不显示。
未完成的子任务、孙任务也按各自状态进入同一列表，并以「子」标记；父任务完成不会自动排除仍未完成的子任务。

- 拖动顶部标题区域移动窗口。
- 每项任务前显示装饰性小圆点。标题按极高、高、中、低、极低优先级分别使用红、橙、褐、紫、灰色。
- 右键任务（或 Shift+F10）打开系统原生菜单，可标记完成、处理中、阻塞、恢复待办、取消，修改优先级及录入百分比与进展说明。菜单可伸出悬浮窗边界，最小高度下也不会被裁切；点击空白处或按 Esc 可关闭。
- 右上角 × 和悬浮设置中的「关闭悬浮窗」均关闭悬浮窗；不会关闭主窗口。
- 点击任务标题返回完整窗口并打开详情；长标题悬停可查看全文。
- 点击右上角展开图标返回完整窗口；刷新图标重新读取任务。
- 右上角「…」打开悬浮设置：默认置顶，可以取消；透明度可选择 0%～60%。
- 窗口尺寸、位置、透明度与置顶偏好自动保存在应用配置，重新打开继续使用。
- 今日标记、截止日期放在同一行，逾期日期使用红色。

两个窗口共用现有任务 API。主窗口、MCP 等入口产生的任务变更会同步到小窗。
小窗启动、获焦及每分钟会重新读取列表，排序使用本地日期。
精简模式是界面状态，没有新增任务存储或数据库表。

未激活时内容区域鼠标穿透，标题栏保留可点击区域。透明度按区域绘制：用户选择 60% 透明时，内容不透明度为 0.4，标题不透明度为 0.7；悬停标题只让标题不透明。单击标题激活后全窗不透明，取消鼠标穿透，失焦恢复。新用户默认内容透明 40%，已保存的透明度继续使用。原生窗口 opacity 保持 1，以避免标题与正文透明度叠乘。
