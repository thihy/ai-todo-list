# 精简悬浮模式

主窗口标题栏的精简模式图标，或托盘菜单「精简悬浮模式」，打开置顶小窗。
小窗内容宽 240px，最多显示 5 条任务，每行 26px，任务减少时自动缩短。
今日待办优先，同组按截止时间从近到远排列，无截止时间排在后面；
相同截止时间按最近更新排序。已完成、已取消、已归档和已删除任务不显示。

- 拖动顶部标题区域移动窗口。
- 点击左侧圆圈完成任务，后续待办自动补位。
- 点击任务标题返回完整窗口并打开详情；长标题悬停可查看全文。
- 点击右上角展开图标返回完整窗口；刷新图标重新读取任务。
- 今日标记、截止日期放在同一行，逾期日期使用红色。

两个窗口共用现有任务 API。主窗口、MCP 等入口产生的任务变更会同步到小窗。
小窗启动、获焦及每分钟会重新读取列表，排序使用本地日期。
精简模式是界面状态，没有新增任务存储或数据库表。
