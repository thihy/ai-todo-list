# 查看绘图实际效果与 PNG 导出

AI 可调用 `drawing_render`，传入已有的绘图 ID：

```json
{ "id": "从 drawing_list 或 app_currentContext 取得的真实 ID" }
```

工具会打开目标绘图、等待画布就绪，并导出当前完整内容。结果包含原生图片
内容块，直接进入下一次模型请求，无需再调用 read_image，也不会把 base64
当作长文本发送。模型可以据此检查文字遮挡、连线穿框、配色和布局。

导出读取当前画布，包含尚未自动保存的编辑、视口外的元素和嵌入图片，不改变
选区、缩放或场景内容。已保存的嵌入图片也随场景加载和保存。PNG 的最长边
最多为 2048 像素；图片附件服务仍会按部署策略验证并规范化输出。

工具会按实际调用会话的模型路由检查视觉能力。纯文本模型会收到明确的换模型
提示，不会记录无法发送给该模型的图片内容。空画布、加载失败、导出失败和
超时也会明确报错。

PNG 缓存在相同任务目录的 `thumbs/{drawingId}.render.png`，复用
TaskDirectoryStore 关联。它是可重复生成的渲染结果，不代替 `.excalidraw`
源文件。原生图片引用由已有 DSH 附件服务持久保存，历史记录可继续引用。

用户也可以点击画布右下方的 **导出 PNG** 下载整张图片。

## 验证记录（2026-10-15）

- 真实 Electron 跨进程导出当前架构图，得到 2048 × 273 PNG，中文、配色、
  节点和连线完整可见。
- 在隔离用户目录和本地兼容模型端点中，模型调用 drawing_render，下一次
  请求实际包含一个 image_url 图片块；工具结果通过持久附件发送。
- 将隔离模型改成纯文本，新会话中的工具调用返回“不支持图片输入”，后续
  请求中的图片数量为零。
- 回归测试覆盖冷画布握手、操作关联、并发、超时、导出失败、完整场景与
