# 消息队列与 Steer

默认快捷键：Enter 排队，Ctrl+Enter 引导当前任务，Shift+Enter 换行，Esc 停止。macOS 的 Cmd+Enter 等同 Ctrl+Enter。在「设置 → 通用 → AI 消息快捷键」可以交换 Enter 与 Ctrl+Enter；空闲时，两种按键都直接发送。

AI 回复期间也可使用输入区的「排队」或「引导」按钮。排队时保存文字和附件快照并清空已提交草稿；输入区继续接收下一条消息。队列中的文字可直接编辑，消息可移除。队列按顺序执行，不会把不同对话的消息混到一起。

停止或调用失败会暂停该对话的队列；点击「继续发送队列」恢复。等待授权或回答问题时不会绕过原有交互。空消息编辑后需要补全或移除。归档对话的队列不发送；删除对话同时移除其未发送消息。

Steer 使用 DSH 原生 next-step inbox，在当前模型步骤结束后引导后续步骤。它不打断已经输出的文字。若对应请求已结束，会转入消息队列；引导失败保留草稿。已接收的引导作为用户消息进入原会话日志，历史恢复时仍可看到。

折叠面板保持已加载的 AI 面板挂载，所以回复和队列继续处理。切换对话不改变消息归属，后台队列依次处理。队列目前保存在本次应用进程的内存中；应用退出或页面重载不会持久化未发送消息。

验证包括真实 Windows Electron 中 Enter 排队、Ctrl+Enter 引导、折叠后队列继续发送、快捷键交换，以及本地模拟模型确认原生 Steer 进入当前任务的下一步。临时模型和服务在测试后移除，原配置恢复。
