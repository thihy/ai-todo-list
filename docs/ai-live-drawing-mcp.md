# AI 实时绘图辅助

打开任务中的绘图，选中图形后直接与 AI 对话，例如：

- “把选中的矩形改成粉红色，文字改为‘已完成’。”
- “在这个节点右边加一个审批节点，并连一条标着‘下一步’的箭头。”
- “只调整这几个节点的位置，保留其他图形。”

AI 读取的是当前画布，包含尚未自动保存的修改、选区和视口。用户说“这些”时以实际选区为范围；无法确定目标时应先询问。修改不重建整张图，也不移动用户的视口。

选中一个或多个元素后，选区旁会显示“AI 标注”输入。输入要求，按 Enter 或点击“暂存”，再为其他选区填写标注。右上角展开标注清单可编辑、删除或定位目标，点击“提交给 AI”合并为一条普通对话消息。助手折叠时会自动展开，忙碌时进入现有队列。标注按绘图本地暂存，切换页面可恢复；缺少模型配置或接收失败时保留草稿。目标已删除时先修正标注，再提交。标注不会直接写入绘图，也不创建任务。

在交互对话中，每次模型调用前都会同步本轮关联画布的实际状态，包含文字、颜色、位置、增删和选区变化；无需 AI 主动调用读取工具，也不会因每次拖动而启动新对话。已发出的模型请求无法中途改写，后续修改仍须通过版本检查。画布关闭或重新打开后，本轮原画布实例失效；后台自动化不会读取前台画布。大场景只提供有明确截断标识的摘要，AI 可按真实 ID 继续查询。

修改完成并落盘后，画布显示“撤销 AI 修改”。点击可恢复最近一批 AI 修改前的内容。如果用户后来又编辑了画布，撤销会拒绝覆盖这些后续变化。关闭画布后，内存中的撤销快照失效。按钮在窄画布下换行，并避开底部原生缩放工具。

## 权限和错误

只读会话可查询画布，但不能修改或撤销。Auto 交给现有 DSH 权限策略判断；工作区权限需要审批，完全访问直接执行。工具失败会把错误交还给模型，不会直接终止整轮对话。

只有保存成功才能确认“已保存”。如果画布已变但保存失败，会明确说明，并保留恢复快照。用户手工修改与 AI 推理并发时，过期修改会被拒绝；被拒绝的请求不会取消用户尚未执行的自动保存。

支持图片输入的模型可以读取实际 PNG 快照。文本模型使用结构化元素；原生 MCP 客户端会明确说明图片输入不可用，仍保留本地 PNG 路径，不能声称已检查图片。

## 实现与边界

参考官方 excalidraw-mcp 的编辑回传和上下文更新思路，保留当前嵌入式画布；不依赖官方仓库、MCP App 页面或远程白板服务。协议仅是内部连接方式，人和 AI 都编辑同一份实时场景。

链路为 DSH 原生 MCP 客户端 → 官方 SDK Streamable HTTP → DrawingCanvasHost → 当前嵌入式 Excalidraw → 现有任务绘图文件。HTTP 服务仅监听随机本地回环端口，使用进程内随机令牌，拒绝浏览器 Origin 请求，并随 DSH 生命周期清理。无需连接另一个远程白板。

工具包括 `get_context`、`read_elements`、`apply_operations`、`get_operation`、`restore_checkpoint` 和 `render_snapshot`，在 DSH 中带 `mcp__drawing__` 前缀。更新操作支持矩形、椭圆、菱形、文字及已有绑定连线；不支持的类型或复杂连线调整会在应用前明确拒绝。形状的内部版本、随机字段和绑定信息由 Excalidraw 官方 API 生成。

`get_actions` 读取当前版本实际注册的全部原生动作，`execute_action` 执行其中任一动作。0.18.1 实际注册 93 项，包括组合、对齐、层级、原生撤销/重做、框架、锁定、样式、剪贴板及原生文件操作；按清单返回的前提和 value 示例调用。另有 5 个仅在类型声明中保留的名称，工具会单独列出，不伪造执行体。完整验收见 [原生动作覆盖](ai-drawing-action-coverage.md)。

模型侧已删除 `drawing_read` 与整图 JSON 写入工具 `drawing_save`。工具失败时修正实时引擎请求，禁止通过文件、Shell 或完整场景 JSON 绕开引擎。普通 UI 文件存储接口继续保留。原生导入/导出使用引擎文件选择器；文件句柄仅在当前编辑器内存中保留，不写入任务文档。

原生粘贴会将焦点定位到画布并等待实际内容与图片数据初始化；剪切先确认复制成功再删除选区。画布关闭后，旧编辑器不能再保存快照。Excalidraw 图片的协作上传标记 `pending` 不代表 AI 仍在执行；本地保存以实际元素、图片文件数据及保存回执为准。

每批最多 100 项操作；快照最多保留 3 个，单个场景快照上限约 5 MB。当前编辑器保留最多 256 个操作结果，主进程保留最多 1024 个；容量耗尽会明确拒绝新操作，不会静默淘汰幂等记录。相同 opId 不重复执行。回执超时表示结果未知，查询原操作并核实画布，不可换 ID 盲目重放。绘图文件仍通过同一个 TaskDirectoryStore 关联保存，没有增加绘图数据库表。

## 验证

单测使用真实 Excalidraw 转换、文字绑定和连线逻辑，覆盖原子校验、并发版本、幂等、保存失败、恢复与悬浮控制层级。协议测试使用真实 SDK、原生 DSH MCP 客户端及工具注册表。

`tests/e2e/live-drawing-mcp.spec.ts` 使用可控模型端点，但 DSH agent loop、MCP HTTP、当前编辑器及文件保存均为真实实现；覆盖选区、重复请求、用户手工并发编辑、冲突后继续、界面撤销、窄窗、文件重开和只读拒绝。

`tests/e2e/live-drawing-real-ai.spec.ts` 可通过 `TODO_E2E_REAL_AI_CONFIG` 指定本地应用配置来显式启用真实模型测试。只复制模型连接配置，在独立临时数据目录验证自然语言修改；不操作原任务或自动化，也不输出密钥。`TODO_E2E_EXECUTABLE_PATH` 可指定打包后的可执行程序，以验证完整安装产物。
