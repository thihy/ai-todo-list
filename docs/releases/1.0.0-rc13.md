# 1.0.0-rc13

发布日期：2026-10-15。Git 标签：`v1.0.0-rc13`。

## 新增与改进

- 新增 `drawing_render`：将完整画布导出为 PNG，以原生图片内容返回视觉模型，用于检查布局、文字遮挡和连线。
- 画布增加“导出 PNG”按钮，包含视口外内容和当前未保存的编辑，最长边最多 2048 像素。
- 绘图保留嵌入图片数据，模型渲染结果通过持久附件服务保存。
- 不支持图片输入的模型会收到明确提示，不会记录无法处理的图片结果。

## 修复

- 修复首次绘图过早报告画布就绪、刷新反复重建编辑器及旧场景覆盖新绘图的问题。
- 连续追加时重映射冲突元素 ID 和箭头绑定；兼容 cylinder 存储节点，以矩形显示。
- 保存前校验整图 JSON，拒绝数组包装和字段类型错误，避免损坏原图后卡在 Loading scene。
- 已有无效场景显示加载错误；绘图快捷键仅在画布内生效，过滤临时编辑和弹窗状态。
- v23 数据库迁移修复已标记 v22 但文档表仍为旧结构的数据，恢复默认“进展”和新增文档能力，保留历史与链接。
- 缺失的进展文件从已有版本恢复，文档操作失败显示明确提示。
- 安装包仅包含正式构建目录，不包含 out 根目录中的本地调试文件。

## 验证

- 全量单元测试：779 通过，4 跳过。
- 类型检查、相关 ESLint 和生产构建通过。
- 真实 Electron 验证 PNG 导出、损坏场景恢复、默认进展与文档新增保存。
- 独立模型端点验证渲染结果以图片内容进入下一次模型请求，并验证纯文本模型拒绝图片。

此前报告的“所有输入框失效”尚未稳定复现；本版修复了已确认的编辑器重挂载和快捷键范围问题，并验证绘图后的输入可用。
