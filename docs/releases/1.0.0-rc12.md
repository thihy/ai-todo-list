# 1.0.0-rc12

发布日期：2026-10-14。Git 标签：`v1.0.0-rc12`。

## 新增与改进

- AI 图片输入支持纯图片提交、缩略图预览和清晰的已发送图片布局。
- 失败消息可重试，保留原文字、附件和意图，并使用当前模型重新发送。
- Windows 截图支持悬停识别窗口、拖动框选、移动选区、确认附加与取消。
- AI 回复期间支持消息排队和原生 Steer。默认 Enter 排队、Ctrl+Enter 引导，可在设置中交换。
- 排队消息可编辑、移除；停止或失败后暂停，折叠面板保持队列运行。
- 文件访问支持完全访问、外部读取逐次审批和只读目录白名单。
- 用户技能按标准 `~/.agents/skills` 发现，支持额外技能目录。

## 修复

- 修复旧模型选择缓存导致自定义模型切换后无法调用的问题。
- 修复绘图工具嵌套参数 schema 导致 DSH 启动失败的问题。
- 隐藏技能目录系统注入消息，修复 AI 面板源码注释显示在界面上的问题。
- 删除任务附件后记录 Git 提交，避免删除状态留在工作树中。
- 收紧目录联接和符号链接的路径判断，覆盖缺失文件的越界路径。
- 修复 Release 上传权限，明确调用 SQLite 原生模块重建脚本，并将重建限定在指定模块。

## 验证

- 全量单元测试：749 通过，4 跳过。
- 类型检查、lint、生产构建通过；lint 有 14 条非阻断警告。
- Windows 实际运行验证了图片预览、截图、重试、排队、Steer、快捷键交换和外部读取审批。
- 附件删除使用真实临时 SQLite 与 Git 仓库验证。

未发送的消息队列目前保存在本次应用运行的内存中，退出应用或重载页面不会持久化。已发送消息和已接收的 Steer 保存在会话历史中。
