# 1.0.0-rc20

本版增加选区 AI 标注批量提交、完整原生绘图动作与独立进展窗口，保留 rc19 的同一画布人机双写机制。

## 用户可见行为

- 选中图形后在旁边输入 AI 标注，逐项暂存，再批量提交。可以编辑、删除、定位标注，切换绘图后恢复草稿。
- 批次是普通对话，助手折叠时自动展开，忙碌时进入队列；接收失败保留草稿，目标删除时明确提示修正。
- AI 可发现并调用 Excalidraw 0.18.1 实际注册的全部 93 个原生 action。5 个类型预留名称独立列出，不冒充已注册动作。
- 删除模型侧 drawing_read、drawing_save；绘图失败不降级读写完整 JSON 文件。支持新增绑定文字的 containerId、水平/垂直对齐，重复绑定会被拒绝。
- 悬浮任务的“录入进展”在独立、不透明的小窗中打开，按屏幕位置放到列表旁边；最小高度 360，保存和取消均不改变原悬浮窗尺寸。
- 修复空对话显示“正在停止”、旧选区执行原生操作、文件句柄导致保存序列化失败，以及原生异步粘贴提前回执的问题。

## 验证范围

- 最终类型检查、生产构建、OpenSpec 严格校验通过；单元测试 867 通过、4 跳过。
- rc20 安装包运行的 9 个重点端到端用例全部通过，打包后的 DSH 启动检查通过。

- 单元测试：已安装开发/生产模块桥接、完整 ActionName 清单、严格参数与真实绑定、延迟选区、权限、文档临时状态、标注提示与草稿恢复。
- 真实 Electron：全部 93 个已注册原生动作逐项调用，另测图片粘贴落盘、剪贴板拒绝时剪切保留原元素且后续操作可继续。
- 操作系统边界使用隔离的 W3C ClipboardItem/Blob 样本与受控文件选择器句柄；绘图动作、图片转换、画布和任务文件持久化均为实际引擎路径。
- 标注端到端：真实选择、两个目标、批量消息、页面切换恢复、折叠助手、忙碌排队、模型未配置时保留草稿、实际原生修改与未创建额外任务。
- 悬浮窗端到端：最小列表高度、独立进展窗口完整可见、不透明、保存/取消与列表尺寸保持。
- 原有自动化、Skill、附加信息、任务通知、流式输出、Steer、执行状态和绘图回归。

真实模型最终复测受到外部服务限制：HTTP 402，`insufficient_balance_error`，Token Plan 用量达到上限。受控模型驱动的真实 DSH、MCP、画布及持久化端到端验证已通过；本版不将受控响应测试描述为真实模型复测通过。
