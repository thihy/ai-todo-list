# 1.0.0-rc19

本版完成实时绘图 MCP 链路，并包含 rc16–rc18 的通知、悬浮窗、工具输出及运行状态修复。

## 本版行为

- 用户手工编辑自动进入 DSH 下一次模型调用的实时绘图上下文，包含文字/样式/选区；绑定具体画布实例，避免跨窗口和后台自动化串入前台画布。

- 用户选中图形后可以直接对话调整现有绘图；DSH 原生 MCP 客户端连接当前嵌入式 Excalidraw，读取未保存的元素、选区和视口。
- 增量修改文字、样式和位置，添加节点并连接已有节点；校验整批操作，拒绝过期版本和不存在的引用，不替换无关内容。
- 相同操作不重复应用，回执超时可查询原执行结果；只有实际保存成功才报告已保存。
- 提供“撤销 AI 修改”；有后续手工编辑时拒绝覆盖。窄画布下按钮换行，操作区不会被交互画布挡住。
- 只读禁止修改，Auto 使用现有权限判断，完全访问直接执行；工具错误交回模型继续处理。
- 修复冲突请求提前取消用户待保存编辑的问题。

## 验收范围

- 类型检查、全量单元测试、生产构建和严格 OpenSpec 验证。
- 真实 Excalidraw 转换/绑定、原生 DSH MCP 客户端/工具注册表、真实 SDK HTTP 和鉴权测试。
- 真实 Electron 场景：选区修改、现有节点连线、幂等、冲突、用户推理期间手工编辑、保存重开、撤销、只读拒绝、普通/窄窗。
- 使用本机已配置的真实模型验证自然语言修改选中矩形，检查原生 MCP 工具调用、真实文件内容和未新增任务。
- 回归自动化同步/分组、任务通知、Skill/系统命令、附加信息、悬浮窗、输出流、取消和 Steer；Steer 进入原任务的下一模型步骤且保留历史。
- Windows 打包产物验证原生 MCP 全链路和 DSH 插件启动。

工具说明与边界见 [AI 实时绘图辅助](../ai-live-drawing-mcp.md)。测试使用隔离数据，不修改用户任务。
